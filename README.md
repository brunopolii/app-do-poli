# app do poli V3 — corrigida

Projeto Flutter organizado para VS Code/Codespaces.

## Recursos
- Início no meio da navegação inferior.
- Agenda com seleção de dia e compromissos.
- Academia com biblioteca ampliada de exercícios.
- Criação e edição de treinos.
- Modo de treino separado da edição.
- Séries, repetições, carga em kg por série e conclusão.
- Alimentação com análise por texto e câmera.
- Estimativa de calorias, proteína, carboidratos e gordura.
- Financeiro com entradas, despesas, categorias e saldo.
- Persistência local com SharedPreferences.
- Tema claro/escuro.

## No Codespaces
Depois de colocar estes arquivos no repositório:

```bash
flutter pub get
flutter analyze
```

Para Android, o ambiente precisa ter Android SDK/Gradle configurados. Se estiver usando GitHub Actions, o APK pode ser compilado na nuvem.
